# Sebastián Illa — Personal Portfolio

A responsive, single-page professional portfolio based on Sebastián Illa's current English CV.

## Files

- `index.html` — main website
- `styles.css` — responsive visual design
- `script.js` — small interactive behaviors
- `Sebastian_Illa_CV_ENG_Version.pdf` — add your CV PDF here before publishing

## Publish with GitHub Pages

1. Create a GitHub repository, for example `sebastian-illa.github.io`.
2. Upload all files in this folder.
3. Make sure the CV PDF is named exactly `Sebastian_Illa_CV_ENG_Version.pdf`.
4. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
5. Your site will be available at your GitHub Pages address.
